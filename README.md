# Analog Clock 

A simple real-time Analog Clock built using HTML, CSS and JavaScript.

## Features

- Real-time clock display
- Hour, minute, and second hands
- Automatic time updates
- Simple and clean design

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

JavaScript uses the current time to calculate the rotation of the hour, minute, and second hands. The clock updates every second.
